# Changelog

## 1.0.1

### Changed

- Require Obsidian 1.4.0 or later, matching the folder creation API used by the plugin.
- Replace ExcelJS with a focused workbook writer and fflate for ZIP compression.
- Update development dependencies and use the standard GPL-3.0 license text.

## 1.0.0

### Added

- Export selected expenses to a formatted Excel workbook, grouped by card and payment source.
- Start an export from the command palette or the editor context menu.
- Save date-stamped workbooks in the vault's `Exports` folder and insert links in the source note.
